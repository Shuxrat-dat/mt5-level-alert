# Multi-Symbol MT5 Level Alert — Отказоустойчивая система алертов уровней

Отказоустойчивая система мониторинга ценовых уровней для **MetaTrader 5** с поддержкой **любых торговых символов** (XAUUSD, USDCHF, EURUSD, GBPUSD, USDJPY, US30, NAS100, BTCUSD и любых инструментов брокера) и отправкой уведомлений в Telegram.

Система поддерживает работу на нескольких терминалах/компьютерах (PC1, PC2...) с автоматическим отказоустойчивым переключением (**failover**) без пропуска алертов и без дублирования сообщений.

---

## 🚀 Ключевые возможности v2.00

- **Настоящий Multi-Symbol**: один советник на одном графике отслеживает уровни **по всем открытым инструментам** терминала.
- **Динамическое определение символов**: инструмент определяется автоматически из свойств графика (`ChartSymbol()`).
- **Сверхбыстрый и экономный мониторинг**:
  - Каждую секунду `OnTimer()` опрашивает live-цены через `SymbolInfoDouble()` для всех символов с активными уровнями (без необходимости держать открытыми сотни окон).
  - На графике с советником работает мгновенная проверка тиков в `OnTick()`.
  - Автоматическое добавление символов в Market Watch (`SymbolSelect(symbol, true)`).
- **Масштабирование порогов цен**:
  - Поддержка универсальных порогов в пунктах (`AlertDistancePoints`) — автоматически масштабируется под любую разрядность (от 5 знаков валют до золота и индексов).
  - Возможность индивидуальных переопределений (`SymbolThresholdOverrides`).
- **Анти-спам и Re-arm**: однократный алерт при подходе к уровню, блокировка повторов вблизи уровня и автоматический повторный взвод (re-arm) после отхода цены за пределы зоны сброса.
- **Отказоустойчивый кластер (Multi-PC)**: только активный компьютер (`ACTIVE`) отправляет уведомления; резервный (`BACKUP`) подхватывает работу за 15 секунд при падении основного.
- **Информативные Telegram-сообщения**: символ, тип события, цена уровня, текущая цена, точная дистанция в пунктах/пипсах, таймфрейм и направление.

## ⚡ Быстрый старт

### 1. Запуск Backend

```bash
cd backend
npm install
cp .env.example .env
# Заполните TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID в .env

# Регистрация ПК:
npm run register-device -- --pc-id=PC1 --priority=1
npm run register-device -- --pc-id=PC2 --priority=2

# Запуск тестов:
npm test

# Сборка и запуск:
npm run build
npm start
```

### 2. Установка в MetaTrader 5

1. Скопируйте `mt5/MultiSymbol_Level_Alert.mq5` в папку терминала: `MQL5/Experts/`.
2. Откройте **MetaEditor** (F4) и нажмите **Скомпилировать** (F7).
3. В MT5 перейдите в `Сервис` → `Настройки` → `Советники`:
   - Включите `Разрешить WebRequest для перечисленных URL` и добавьте ваш URL (например `https://ваш-домен.com` или `http://localhost:8080`).
   - Включите `Разрешить алгоритмическую торговлю`.
4. Перетащите советник `MultiSymbol_Level_Alert` на **любой график** (например, EURUSD M5).
5. Укажите параметры во вкладке `Входные параметры`:
   - `BackendURL`: URL вашего сервера.
   - `PC_ID`: `PC1`.
   - `DeviceToken`: токен, полученный при выполнении `register-device`.

### 3. Создание уровней

Просто нарисуйте горизонтальную линию (`OBJ_HLINE`) на графике **любого инструмента** (USDCHF, EURUSD, XAUUSD, US30, BTCUSD...).
Советник сам:
- Определит символ графика;
- Назначит линии уникальный UUID;
- Зарегистрирует уровень на сервере;
- Начнет проверять цену каждую секунду;
- При подходе цены отправит информативный алерт в Telegram!

Подробную инструкцию см. в [docs/INSTALL.md](docs/INSTALL.md).
