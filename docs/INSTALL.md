# Полная инструкция по установке с нуля: Multi-Symbol Level Alert v2.00

Данная инструкция написана для обычного пользователя Windows и содержит все шаги: от создания Telegram-бота до настройки MetaTrader 5 и создания уровней на разных инструментах.

---

## 📋 Системные требования

1. **Сервер для бэкенда**:
   - Любой VPS (Ubuntu 22.04+ или Debian 11+) с Node.js >= 18.0.0 и npm.
   - Либо ваш домашний ПК / Docker Desktop (для локального тестирования).
2. **Терминал**:
   - MetaTrader 5 (актуальный билд).
   - Установленный на одном или нескольких компьютерах (PC1, PC2 и т.д.).
3. **Мессенджер**:
   - Telegram аккаунт для получения уведомлений.

---

## ЧАСТЬ 1. Создание и настройка Telegram-бота

### Шаг 1. Создать бота через @BotFather
1. Откройте Telegram и в строке поиска найдите официального бота: **`@BotFather`** (с синей галочкой).
2. Нажмите кнопку **Start** или отправьте команду:
   ```text
   /newbot
   ```
3. BotFather попросит указать имя бота (отображаемое имя). Введите, например:
   ```text
   MultiSymbol Alert Bot
   ```
4. Затем BotFather попросит указать юзернейм бота (должен оканчиваться на `bot`). Введите, например:
   ```text
   my_level_alert_bot
   ```
5. BotFather поздравит вас и пришлёт сообщение с токеном вида:
   ```text
   7123456789:AAFlm..._ВАШ_ТОКЕН_...
   ```
   **Это ваш `TELEGRAM_BOT_TOKEN`. Скопируйте его.**

---

### Шаг 2. Создать группу в Telegram для уведомлений
1. В Telegram создайте новую группу: меню `≡` → `New Group` (Создать группу).
2. Назовите группу, например: **`Trading Alerts`**.
3. Добавьте в эту группу вашего созданного бота (по его `@юзернейму`).
4. **Важно (Отключить Privacy Mode)**:
   - Вернитесь в чат с `@BotFather`.
   - Отправьте команду: `/mybots`
   - Выберите вашего бота → `Bot Settings` → `Group Privacy` → `Turn off`.
   - Должно появиться подтверждение: *Privacy mode is disabled*.

---

### Шаг 3. Узнать CHAT_ID группы
1. Напишите любое сообщение в вашу созданную группу (например: `Привет`).
2. Откройте браузер и перейдите по ссылке (замените `<ВАШ_BOT_TOKEN>` на токен из Шага 1):
   ```text
   https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/getUpdates
   ```
   *(Пример: `https://api.telegram.org/bot7123456789:AAF.../getUpdates`)*
3. В открывшемся тексте найдите блок `"chat"`:
   ```json
   "chat": {
     "id": -1002345678901,
     "title": "Trading Alerts",
     "type": "supergroup"
   }
   ```
4. Число со знаком минус (например, `-1002345678901`) — это ваш **`TELEGRAM_CHAT_ID`**. Скопируйте его полностью вместе с минусом.

---

### Шаг 4. Проверка отправки тестового сообщения
Чтобы убедиться, что бот и чат работают, выполните в командной строке или браузере:
```bash
curl -X POST "https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/sendMessage" \
     -H "Content-Type: application/json" \
     -d "{\"chat_id\": \"<ВАШ_CHAT_ID>\", \"text\": \"🔔 Тестовое сообщение от бота успешно доставлено!\"}"
```
В группе появится сообщение от бота.

## ЧАСТЬ 2. Установка и запуск Backend

### Шаг 5. Клонирование и установка зависимостей
Откройте терминал (на сервере или PowerShell в Windows):

```bash
# Перейдите в каталог проекта
cd backend

# Установите зависимости
npm install
```

### Шаг 6. Настройка `.env` файла
Создайте файл `.env` из шаблона:
```bash
cp .env.example .env
```
Откройте файл `.env` в любом текстовом редакторе (Notepad, nano, VS Code) и укажите ваши параметры:
```env
# Порт сервиса
PORT=8080

# Путь к базе данных (создается автоматически)
DB_PATH=./data/coordination.db

# Токен бота из Шага 1
TELEGRAM_BOT_TOKEN=7123456789:AAFlm...

# ID группы из Шага 3 (обязательно с минусом)
TELEGRAM_CHAT_ID=-1002345678901

# Интервалы кластера (секунды)
HEARTBEAT_INTERVAL_SEC=5
FAILOVER_TIMEOUT_SEC=15
LEASE_DURATION_SEC=20
PROMOTION_STABLE_SEC=10
NOTIFICATION_MIN_INTERVAL_SEC=3

LOG_LEVEL=INFO
```

### Шаг 7. Регистрация устройств (ПК) и получение токенов
Каждый компьютер, на котором будет работать MT5, должен иметь свой уникальный идентификатор (`PC_ID`) и секретный токен (`DeviceToken`).

Выполните команду для первого ПК:
```bash
npm run register-device -- --pc-id=PC1 --priority=1
```
В консоли появится:
```text
Device registered.
  PC_ID        = PC1
  PRIORITY     = 1
  DEVICE_TOKEN = dtok_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
```
**Сохраните `DEVICE_TOKEN` для PC1!**

Если у вас есть второй резервный компьютер (PC2):
```bash
npm run register-device -- --pc-id=PC2 --priority=2
```
Сохраните отдельный токен для PC2.

### Шаг 8. Сборка и запуск бэкенда
```bash
# Сборка TypeScript
npm run build

# Запуск тестов (убедитесь, что все 40 тестов пройдены)
npm test

# Запуск сервера
npm start
```
Сервер готов и слушает порт 8080.
Для постоянной работы 24/7 на Linux сервере используйте:
```bash
pm2 start dist/src/server.js --name alert-backend
pm2 save
pm2 startup
```
Либо через Docker:
```bash
docker compose up -d --build
```

Проверка статуса:
```bash
curl http://localhost:8080/health
# Ответ: {"ok":true,"time":"..."}

curl http://localhost:8080/status
```

> **Важно про HTTPS**: Для работы функции WebRequest в MetaTrader 5 рекомендуется использовать защищенное HTTPS-соединение (например, разместив за Nginx/Caddy с бесплатным сертификатом Let's Encrypt).

## ЧАСТЬ 3. Установка советника (EA) в MetaTrader 5

### Шаг 9. Копирование советника
1. Откройте **MetaTrader 5**.
2. В верхнем меню нажмите: **`Файл` → `Открыть каталог данных`** (File → Open Data Folder).
3. Перейдите в папку: **`MQL5` → `Experts`**.
4. Скопируйте файл советника **`mt5/MultiSymbol_Level_Alert.mq5`** в эту папку.

### Шаг 10. Компиляция советника в MetaEditor
1. В MetaTrader 5 нажмите клавишу **`F4`** (или меню `Сервис` → `Редактор MetaQuotes Language`).
2. В панели «Навигатор» слева раскройте папку `Experts` и дважды кликните по файлу **`MultiSymbol_Level_Alert.mq5`**.
3. На верхней панели инструментов нажмите кнопку **`Скомпилировать`** (Compile, или клавиша **`F7`**).
4. В нижней панели «Ошибки» убедитесь, что появилась строка:
   ```text
   Result: 0 errors, 0 warnings
   ```
   В папке появится скомпилированный файл `MultiSymbol_Level_Alert.ex5`.

### Шаг 11. Разрешение сетевых запросов (WebRequest)
1. В MT5 перейдите в меню: **`Сервис` → `Настройки`** (Tools → Options) или нажмите `Ctrl + O`.
2. Перейдите на вкладку **`Советники`** (Expert Advisors).
3. Установите галочку: **`Разрешить WebRequest для перечисленных URL`**.
4. В поле добавьте базовый URL вашего бэкенда (без путей и слэшей на конце):
   ```text
   https://ваш-домен.com
   ```
   *(или `http://IP_ВАШЕГО_СЕРВЕРА:8080`, если тестируете без SSL)*.
5. Убедитесь, что также включена опция **`Разрешить алгоритмическую торговлю`** (Allow Algo Trading).
6. Нажмите **OK**.

### Шаг 12. Запуск советника на графике
1. Откройте **любой график** в MT5 (например, `EURUSD` или `XAUUSD`, таймфрейм M5 или H1).
2. В окне «Навигатор» найдите раздел **Советники** → **`MultiSymbol_Level_Alert`**.
3. Перетащите советник мышкой на открытый график.
4. В появившемся окне настроек:
   - Вкладка **Общие**: включите **`Разрешить алгоритмическую торговлю`**.
   - Вкладка **Входные параметры**:
     - `BackendURL`: `https://ваш-домен.com` (или ваш IP с портом 8080)
     - `PC_ID`: `PC1`
     - `DeviceToken`: токен, полученный в Шаге 7 для PC1
     - `AlertDistancePoints`: 30 (пункты по умолчанию)
     - `SymbolThresholdOverrides`: строка индивидуальных порогов (можно оставить стандартную)
5. Нажмите **OK**.
6. В правом верхнем углу графика появится значок шляпы советника (синий цвет = алгоритмическая торговля включена).
7. Откройте вкладку **«Эксперты»** внизу терминала. Там появятся записи:
   ```text
   [INFO] Multi-symbol monitor started
   [INFO] PC_ID: PC1
   [INFO] Backend: https://...
   [INFO] *** Promoted to ACTIVE ***
   ```

## ЧАСТЬ 4. Как создавать уровни и получать алерты

Вам **НЕ нужно** ставить по советнику на каждый график. **Один запущенный EA обслуживает все графики терминала!**

### Пример 1: Создание уровня на USDCHF
1. Откройте график **`USDCHF`** (любой таймфрейм, например H1).
2. На панели инструментов MT5 выберите инструмент **«Горизонтальная линия»** (Horizontal Line).
3. Нажмите на графике, установив линию рядом с текущей ценой (например, цена `0.87500`).
4. В течение 1–5 секунд советник автоматически обнаружит линию:
   - Линия на графике переименуется в `LVL_<уникальный_UUID>`.
   - В логах советника появится запись:
     ```text
     [INFO] New level created: [USDCHF] H1 @ 0.87500
     [INFO] Monitoring USDCHF (1 level(s))
     ```
5. Как только текущая цена подойдет к `0.87500` на расстояние алерта, в Telegram придет уведомление:
   ```text
   🔔 LEVEL HIT

   📌 Symbol: USDCHF
   📍 Level:  0.87500
   💰 Price:  0.87508
   📏 Distance: 0.00008
   📊 Timeframe: H1
   📈 Direction: UP ▲

   🖥 Active: PC1
   ⏰ 2026-09-15 10:35:00 UTC
   ```

### Пример 2: Создание уровня на EURUSD
1. Откройте график **`EURUSD`**.
2. Поставьте горизонтальную линию, например на `1.17000`.
3. Советник обнаружит её и начнет мониторить EURUSD параллельно с USDCHF.

### Пример 3: Создание уровня на XAUUSD (золото)
1. Откройте график **`XAUUSD`**.
2. Поставьте горизонтальную линию, например на `4500.00`.
3. Советник сразу подключит мониторинг XAUUSD.

## ЧАСТЬ 5. Защита от спама и повторные алерты

1. **Когда цена колеблется прямо на уровне**:
   - Бот присылает алерт ровно **один раз**.
   - Повторные сообщения блокируются механизмом идемпотентности на бэкенде.
2. **Re-arm (повторный взвод алерта)**:
   - Если цена отходит от уровня дальше расстояния сброса (`ResetDistance`), советник отправляет событие `RESET`.
   - В логе появляется: `[DEBUG] Level re-armed`.
   - При следующем возвращении цены к уровню алерт сработает снова!
