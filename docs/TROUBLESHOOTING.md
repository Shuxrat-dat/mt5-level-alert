# Руководство по устранению неполадок (Troubleshooting)

## 1. Ошибки сетевых запросов в MT5

### `[ERROR] WebRequest failed (err=4060)`
- **Причина:** Базовый URL бэкенда не добавлен в список разрешенных адресов терминала.
- **Решение:**
  1. В MT5 откройте: `Сервис` → `Настройки` → вкладка `Советники`.
  2. Убедитесь, что стоит галочка `Разрешить WebRequest для перечисленных URL`.
  3. Добавьте ваш URL строго в формате:
     ```text
     https://ваш-домен.com
     ```
     (без путей, без параметров и без слэша `/` на конце!).
  4. Перезапустите советник (снимите с графика и перетащите заново).

### `[ERROR] WebRequest failed (err=5203)` или `(err=5200)`
- **Причина:** Бэкенд физически недоступен по указанному адресу или заблокирован файрволом.
- **Решение:**
  1. Проверьте в браузере или через curl доступность:
     ```bash
     curl https://ваш-домен.com/health
     ```
  2. Убедитесь, что сервис бэкенда запущен: `pm2 status` или `docker compose ps`.
  3. Проверьте, открыт ли порт (по умолчанию 8080) в сетевом экране вашего VPS (UFW, Security Groups).

## 2. Проблемы с символами и котировками

### `[WARN] Symbol <СИМВОЛ> is not available from this broker`
- **Причина:** Уровень создан на символе, которого нет у брокера или у брокера другое суффиксное обозначение (например, `GOLD` вместо `XAUUSD`, или `USDCHF.m` вместо `USDCHF`).
- **Решение:**
  - Советник автоматически пытается добавить символ в «Обзор рынка» с помощью `SymbolSelect(symbol, true)`.
  - Убедитесь, что открыт график с правильным тикером, который котирует именно ваш брокер.

### `[ERROR] Failed to get price for <СИМВОЛ>`
- **Причина:** `SymbolInfoDouble(symbol, SYMBOL_BID)` вернул `<= 0`.
- **Решение:**
  1. Проверьте, включен ли этот символ в окне «Обзор рынка» (Market Watch). Нажмите `Ctrl+M` в MT5, правой кнопкой мыши → `Показать все символы`.
  2. Проверьте, открыт ли рынок по данному инструменту в текущий момент (выходные, праздники, перерыв торговой сессии).

## 3. Авторизация и роли (ACTIVE / BACKUP)

### `role` не переключается в ACTIVE ни на одном ПК
1. Проверьте логи бэкенда (`pm2 logs` или консоль). Если там видны ошибки `401 Unauthorized`:
   - Значит `DeviceToken` указан неверно или скопирован с лишними пробелами.
   - Зарегистрируйте устройство заново:
     ```bash
     npm run register-device -- --pc-id=PC1 --priority=1
     ```
     и скопируйте напечатанный токен точно в настройки советника.

### PC2 не забирает роль при отключении PC1
- По умолчанию переключение происходит через `FAILOVER_TIMEOUT_SEC` (15 секунд) после последнего полученного heartbeat от PC1.
- Проверьте `/status`:
  ```bash
  curl http://localhost:8080/status
  ```
  Убедитесь, что PC2 успешно отправляет heartbeat (в статусе должно быть `online: true`).

## 4. Уведомления в Telegram

### Сообщение не приходит в Telegram
1. **Проверьте права бота в группе:**
   - Бот должен быть добавлен в группу участником.
   - Privacy Mode в `@BotFather` должен быть отключен (`/mybots` → `Bot Settings` → `Group Privacy` → `Turn off`).
2. **Проверьте ID чата:**
   - Для групп `TELEGRAM_CHAT_ID` **всегда начинается со знака минус** (например, `-1001234567890`). Если минус опущен, Telegram не доставит сообщение в группу.
3. **Проверьте лог очереди:**
   - Откройте `http://localhost:8080/status`. Если в `recent_notifications` статус `failed`, бэкенд не смог связаться с API Telegram. Проверьте валидность `TELEGRAM_BOT_TOKEN`.
   - Встроенный `retryWorker` автоматически пытается переотправить неудачные уведомления в течение 1 часа.

### Приходит два одинаковых сообщения
1. Убедитесь, что вы не запустили две копии бэкенда с разными базами данных.
2. Проверьте, что советник запущен на одном графике терминала (не нужно вешать советник на каждый график, он сам сканирует все открытые графики).
3. Проверьте, что на одной цене не нарисовано две одинаковые линии с разными UUID.

## 5. Компиляция в MetaEditor

### Ошибки при нажатии F7 (Compile)
- Убедитесь, что компилируете именно файл **`MultiSymbol_Level_Alert.mq5`** в MetaEditor для MetaTrader 5 (не MetaTrader 4!). MQL4 и MQL5 имеют разные API.
- Убедитесь, что билд MetaTrader 5 не устарел.
